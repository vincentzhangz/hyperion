# Security Policy

Hyperion is a single-tenant scraping service. Operators are trusted; navigated URLs are not.

## Reporting a vulnerability

Do not open a public issue for security bugs.

1. Use GitHub Security Advisories on this repository, or
2. Email the maintainer listed on the GitHub profile.

Please include reproduction steps, affected versions, and impact.

## Operator guidance

See [docs/security.md](docs/security.md) for authentication, SSRF policy, profile isolation, preview sandboxing, and container hardening.
